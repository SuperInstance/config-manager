# config-manager

Multi-language configuration management solution — Go and Rust implementations for fleet-wide config handling.

## What This Gives You

- **Multi-language support** — Go and Rust implementations
- **Fleet-compatible** — designed for Cocapn Fleet vessel configuration
- **Charter documentation** — project scope and milestones defined

## Quick Start

```bash
git clone https://github.com/SuperInstance/config-manager.git
cat CHARTER.md  # Project scope and goals
```

## How It Fits

Configuration infrastructure for the SuperInstance ecosystem.

Related repos:
- [config-vault](https://github.com/SuperInstance/config-vault) — fleet config management Worker
- [config-rs](https://github.com/SuperInstance/config-rs) — Rust config library
- [cocapn-core](https://github.com/SuperInstance/cocapn-core) — core fleet library
